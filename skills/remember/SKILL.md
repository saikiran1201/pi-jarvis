# Remember

When the user says "remember this", "keep in mind", or states a lasting preference:

1. Capture the fact in one clear sentence with enough context to stand alone.
2. Store it via the memory skill (`pi-hermes-memory`) tagged with the topic (e.g. `work`, `health`, `preference`).
3. Confirm in ≤ 1 line what was stored. If it contradicts an existing memory, ask which is current — never silently overwrite.
