# Web Research

1. Use `pi-web-access` (`web_search`, `fetch_content`) — one search per sub-question, never both tools for the same query.
2. Prefer primary sources (official docs, papers, release notes) over blog summaries.
3. Report: a 5-line answer first, then bullet details, each with its source URL.
4. If sources conflict, say so explicitly instead of picking one silently.
